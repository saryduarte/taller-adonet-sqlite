# Actividad Formativa: Introducción a ADO.NET y SQLite en C#

Aplicación de consola desarrollada en *C# (.NET 8)* que demuestra el acceso y persistencia de datos local utilizando *ADO.NET* (Microsoft.Data.Sqlite v8.0.11).

## Requisitos previos
- .NET 8 SDK instalado.
- Visual Studio Code o Visual Studio.
